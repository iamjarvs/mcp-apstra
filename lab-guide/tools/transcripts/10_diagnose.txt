Troubleshooting tips:
  - If you see 'Connection refused', the host is not reachable. Check:
    • Is the IP/hostname correct?
    • Is the Apstra instance running?
    • Is there a firewall blocking port 443?

  - If you see 'SSL' errors:
    • Make sure APSTRA_SSL_VERIFY=false (or omit it, defaults to false)
    • Self-signed certificates are normal for Apstra deployments

  - If you see '401 Unauthorized':
    • Check your username and password
    • Verify APSTRA_USERNAME and APSTRA_PASSWORD are set correctly
